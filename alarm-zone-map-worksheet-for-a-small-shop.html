Alarm Zone Map Worksheet for a Small Shop

Published by Eyonic CCTV.

A practical worksheet for Sarawak shop managers to draw each room, assign alarm zones and record which sensor covers which door or window, so a false alarm can be traced to a named zone.

Why a zone map earns its place before the alarm goes in

A burglar alarm system is only as useful as the information staff can act on when it triggers. If the keypad shows a number and nobody knows which door, window or room that number belongs to, the response becomes a guess. Someone walks the whole shop checking every opening while a real event may be happening elsewhere, or a false alarm gets dismissed without anyone learning why it happened.

A zone map fixes that by turning numbers into places. It is a one-page drawing of your premises with each detection area labelled, plus a table that says which sensor sits on which opening and which zone it reports to. Done before installation, it also gives the installer a shared reference so the finished system matches what you thought you were buying. Done after installation, it becomes the document you reach for when a zone keeps triggering at the same time each week.

This guide is written for premises managers in Sarawak planning an ordinary small-shop alarm project. It is a worksheet and a set of questions, not wiring guidance. Anything involving the panel, cabling or sensor adjustment belongs with the installer. Step one: draw the shop as it actually is

Start with a rough floor plan, not a neat architectural drawing. Walk the premises with a clipboard and sketch what is there: the front entrance, any side or rear door, roller shutters, windows that open, the counter, the stockroom, the staff area, the toilet corridor and any shared wall with a neighbouring unit. Mark fixed furniture that will not move, such as shelving runs and the counter, because these affect what a sensor can see.

Add the things that change during the day. A back door that is propped open during deliveries is a different alarm problem from one that stays shut. A window above a display that staff open for ventilation in the afternoon needs to be noted as an opening, not treated as fixed glass. If your shop shares a corridor or service lane with other units, mark the boundary so nobody assumes coverage that is not there.

Label each room with a short name you will actually use: Front Shop, Counter, Stockroom A, Rear Door, Staff Room. These names will become your zone names, so keep them plain and consistent. Avoid codes only one person understands. The test is simple: could a new supervisor read the map at 7am and know where to look?

Finish this step by photographing the sketch and noting the date. Layouts change when shelving moves or a partition goes up, and a dated drawing tells you when the map needs revisiting.

Step two: assign zones in a way staff can act on

A zone is a group of detection points that the panel reports together. How you group them decides how useful the alarm is. Two common approaches are by physical area and by opening type, and each has trade-offs.

Area-based zoning groups everything in one room together: all Stockroom sensors on one zone, all Front Shop sensors on another. This suits a shop where staff respond by walking to a room and checking it. Opening-based zoning groups by type instead, for example all perimeter doors on one zone and all internal movement detectors on another. This can suit a premises where the first response is to check whether the building envelope was breached.

For a small shop, a practical middle path is to give each external opening its own zone where the panel allows, then group internal rooms. That way a 2am trigger tells you whether the issue is a door to the outside or movement inside, which are different situations. Write the zone list as a numbered table with a plain name beside each number, and leave a column for the sensor reference the installer will fill in.

Keep the list short enough to memorise. If you find yourself with fifteen zones for a single shop lot, ask the installer whether some can be combined without losing the ability to tell one opening from another. The goal is traceability, not maximum count.

Step three: the sensor-to-opening record

This is the part most shops skip, and it is the part that makes false alarms traceable. Build a table with one row per detection point. Suggested columns, as an example format rather than a standard:

Zone number, zone name, location description, opening or area covered, sensor type as described by the installer, date installed, and a notes column for anything that affects reliability.

Fill the location description in your own words, not the installer's shorthand. "Rear door, left leaf, above frame" is more useful to a supervisor than a model code. In the notes column, record practical context: a door that sticks in wet weather, a window near a hot display that staff open at midday, a stockroom entrance where trolleys pass close to the sensor. These notes are what let you connect a repeat trigger to a physical cause instead of shrugging it off.

Ask the installer to walk the table with you at handover and confirm each row against the actual device. If a sensor covers two openings, say so explicitly rather than listing one. If a zone was combined, note which openings share it. A record that overstates coverage is worse than no record, because it creates false confidence.

Keep the completed table with the panel documentation and the keyholder list, in a place the duty manager can reach without calling the owner.

Step four: a false-alarm trace log

A zone map becomes genuinely useful when you pair it with a short log of every trigger. The log does not need software. A notebook or a shared document with five columns is enough: date and time, zone number reported, what staff found on arrival, whether it was a genuine event or a false trigger, and what was changed afterwards.

After a few entries, patterns usually appear. A zone that triggers on windy afternoons may point to a loose fitting or a door that moves. A zone that triggers shortly after closing may point to staff leaving through a different route than assumed. A zone that triggers when the shutter is raised may point to vibration or a sensor positioned where the shutter movement reaches it. You do not need to diagnose the cause yourself; the log gives the installer a specific, dated description to work from instead of a vague report that the alarm keeps going off.

Set a simple review rhythm. Looking at the log monthly, or after any week with more than one trigger, is a reasonable author heuristic rather than a researched standard. Bring the log to any service visit. If a zone has never triggered in a year of normal operation, that is also worth noting, because it may mean the area is untested rather than quiet.

Keep the log factual. "Zone 3 triggered at 14:20, rear door found closed, no entry signs, wind strong" is useful. "Alarm faulty again" is not.

Step five: connect the map to the rest of the premises plan

The alarm zone map should not live alone. A small shop usually has several systems whose records need to agree, and mismatches between them cause confusion during an incident.

If the shop has cameras, note on the zone map which camera view covers each opening, so a trigger can be checked against footage. Camera placement decisions and the alarm layout are easier to review together than separately, and a site survey is the natural moment to do both. If the premises uses controlled door entry, record which doors are on the alarm and which are on the access system, and who holds permissions for each. Smart lock door access is described by the supplier as good for controlled convenience when user permissions and backup entry are planned properly, which is a reminder that door hardware decisions and alarm zoning should be discussed in the same conversation rather than months apart.

For shops with a keyphone system, note the number the alarm notification reaches and who answers it at night. For premises with a queue management system at the counter, check that any counter-side sensor or keypad is not placed where public traffic will knock or obstruct it.

Write a single line on the map naming who owns the document, who may update it, and where the current version is kept. That one line prevents the common situation where three people each hold a different version of the layout.

A handover checklist for the completed map

Use this as a closing check when the alarm work is done or when a manager changes. Each item is a yes or no, and anything marked no gets a named person and a date.

One: the floor plan is dated and matches the current layout, including any partition or shelving change since the drawing was made. Two: every zone number has a plain name a new supervisor would recognise. Three: the sensor-to-opening table has a row for every detection point, with combined coverage stated openly. Four: the installer has walked the table with a member of staff and confirmed each row. Five: the false-alarm log exists, is reachable, and has at least one entry format agreed. Six: the map notes which camera views correspond to which openings. Seven: the notification contact list is current and includes a named backup. Eight: the document owner and storage location are written on the map itself.

Two further questions are worth asking at handover, and both stay at the level of process rather than technical detail. Who runs a test of each zone with staff present, and when? And who is authorised to request a change to the system, so that adjustments are not made informally by whoever happens to be on shift?

A zone map is a small document. Its value comes from being accurate, dated and used. If it is drawn once, filed, and never opened again, it will not help anyone at 2am. If it is reviewed when the layout changes and paired with a trigger log, it turns a burglar alarm system from a box on the wall into something the shop can actually manage.
